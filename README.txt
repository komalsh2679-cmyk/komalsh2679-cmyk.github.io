PUBLISH WITH GITHUB PAGES
1. Extract this ZIP file on your computer.
2. Open your GitHub repository for the portfolio.
3. Upload the contents of this folder (not the outer folder itself), keeping the papers folder and its PDF in place.
4. Commit the changes.
5. In the repository settings, open Pages and select the main branch and root folder if Pages is not already enabled.
6. Open your GitHub Pages website and test all navigation links and both research-paper buttons.
