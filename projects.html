NeuroDocs — RAG Document Assistant

I built a document-based question-answering application using Retrieval-Augmented Generation (RAG). Users can upload PDF documents, process them, and ask questions grounded in the document content. FAISS retrieves relevant information, while a locally running TinyLlama model generates answers through Ollama.

PDF upload and processingFAISS similarity retrievalLocally run LLM through OllamaSuggested questions and conversational memory

This is a learning prototype. Answer quality and source grounding should be checked against the uploaded documents.

Café Sales Dashboard

An end-to-end Power BI dashboard built in Power BI Desktop using a 3,200-row café sales CSV covering the full year of 2025.

What I built

Cleaned data in Power Query, fixing a US date-locale import issue, hidden spaces that created a false category, and incorrect column typesBuilt a 365-day DAX calendar table related to the sales fact table in a star-schema-style modelCreated 11 DAX measures, including cumulative profit % and a disconnected-table SWITCH measure for a cost waterfallDesigned 9 visuals: KPI cards, payment-method donut, cost waterfall, combo chart, item volume-vs-margin scatter, item-by-month heatmap, and interactive tile slicers

Business purpose: explore sales and revenue trends, cost breakdowns, profitability, payment methods, and product-level patterns through interactive filters and tables.

The figures shown are the dashboard’s reported metrics. A live report link can be added after publication to Power BI Service and confirmation of its sharing settings.
